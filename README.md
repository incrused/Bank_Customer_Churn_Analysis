Комплексный анализ оттока клиентов банка с выявлением ключевых факторов риска, построением прогнозной модели и разработкой практических рекомендаций для бизнеса.

## 📊 О проекте

Дипломный проект по профессии "Аналитик данных", в котором проведен полный цикл анализа данных от предобработки до построения ML-модели и бизнес-рекомендаций.

**Ключевые результаты:**
- Выявлены 3 критические группы риска с оттоком до 69.5%
- Построена модель логистической регрессии с точностью 80.3%
- Разработаны целевые программы удержания для ключевых сегментов
- Статистически подтверждено влияние возраста и баланса на отток

## 📈 Ключевые инсайты

### Основные метрики оттока
- **Общий уровень оттока:** 20.4% (2,038 клиентов)
- **Сохранившиеся клиенты:** 79.6% (7,962 клиентов)

### Критические сегменты риска
- **Германия:** 32.4% оттока (в 1.6× выше среднего)
- **Клиенты 51-60 лет:** 56.2% оттока (в 2.8× выше среднего)
- **Неактивные клиенты:** 26.9% оттока (в 1.9× выше активных)

### Статистически подтвержденные гипотезы
- **Возраст:** Ушедшие клиенты старше на 7.7 лет (p < 0.001)
- **Баланс:** Ушедшие клиенты имеют на +19,000 выше баланс (p < 0.001)

## 💡 Бизнес-рекомендации

### Приоритетные меры
1. **VIP-клиенты** - персональные менеджеры для клиентов 40+ с балансом >100,000
2. **Немецкий рынок** - исследование причин аномального оттока
3. **Реактивация** - программа возврата неактивных клиентов

### Целевые программы удержания
- "Зрелые инвесторы" - мужчины 45+ с высоким балансом
- "German Priority" - программа для немецкого рынка
- "Оптимальный пакет" - стимулирование перехода на 2 продукта
